# AppCreator · Brand Spec

## Product
AI-powered enterprise management application generator. Users chat with AI to create
production-ready enterprise applications (admin panels, ERP modules, approval workflows,
HR systems) as single HTML prototypes. Prototypes are free to preview/download;
deployable source code packages require purchase. Each user = an isolated namespace.

**Scope**: Enterprise management applications ONLY (B2B). NOT consumer-facing products.

## Design Language
Inspired by v0.dev (clean dark + emerald) and bolt.new (structured dark + purple),
but with AppCreator's own enterprise-grade identity.

- **Primary accent**: Deep sapphire (#2563EB) → conveys trust, authority, enterprise reliability.
  Not the generic purple gradient (AI slop).
- **Background**: Deep neutral (#0A0A0F → #1A1A2E) — professional, technical.
- **Typography**: System font stack for body; monospace for code/prompt elements.
- **Grid**: Structured, data-dense, professional. Not whimsical.
- **Tone**: Enterprise, authoritative, efficient. "Build management apps, not toys."
